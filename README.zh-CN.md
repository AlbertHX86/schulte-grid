# 舒尔特方格

[English](README.md) | 中文

一个在浏览器里运行的极简舒尔特方格小游戏。没有广告，不用注册，也没有任何依赖。

**在线试玩：** https://alberthx86.github.io/schulte-grid/

## 怎么玩

1. 选择方格大小：3×3 到 7×7。5×5 是最经典的。
2. 点击 **1**，开始计时。
3. 按顺序找到并点击数字 1、2、3……直到最后一个。“下一个”显示当前要找的数字。点错会闪红，不算数。
4. 点完最后一个数字后停止计时，成绩自动保存到“记录”。
5. 点击“重置”，重新打乱方格。

小技巧：

- 目光尽量停在方格中央，用余光去找数字，而不是一格一格地扫。
- 短时间练习效果更好：每天一两次，每次几轮。
- 和自己比。看“记录”里的变化趋势，而不是某一轮的快慢。

右上角可以切换亮色和暗色，以及中文和英文。默认跟随系统主题和浏览器语言。

## 记录

每种方格大小单独记录：最佳成绩和最近 10 轮。记录保存在浏览器的 `localStorage` 里，不会上传到任何地方。

- 同一设备的同一浏览器会一直保留记录，在线离线都可以。
- 不同浏览器、不同设备之间不同步。
- 清除浏览器数据会删掉记录。也可以点“清空”，删除当前大小的记录。

## 本地运行

游戏只有三个静态文件：`index.html`、`style.css`、`app.js`，不需要构建。

```bash
git clone https://github.com/AlbertHX86/schulte-grid.git
cd schulte-grid
```

然后直接用浏览器打开 `index.html`，或者起一个本地服务：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

直接打开文件和通过 `localhost` 访问，在浏览器看来是两个不同的网站，记录分开保存。想对比成绩的话，固定用其中一种方式。

## 舒尔特方格与前额叶

舒尔特方格是一张打乱顺序的数字表，要求按顺序把数字找出来。它以德国精神科医生 Walter Schulte 命名，长期以来在心理学中用来测量注意力：一个人在视野中搜索目标有多快、有多稳定。

完成一轮需要用到好几种依赖额叶（特别是前额叶皮层）和顶叶注意网络的能力：

- **持续注意：** 整轮都保持专注。
- **工作记忆：** 边找边记住当前要找的数字。
- **抑制控制：** 忽略已经找过的数字和后面才轮到的数字。
- **视觉搜索与眼动：** 高效扫视，善用余光。

所以很多人把它当作一种简短、轻松的注意力练习，比如学习前热身，或者从满是通知的屏幕里歇一会儿。

**对它的作用要有合理预期。** 多练确实会让你玩舒尔特方格越来越快。但目前证据有限，不能说明这种进步会迁移到日常注意力或其他任务上；也没有可靠证据表明它能修复前额叶，或治疗 ADHD、脑损伤等任何疾病。把它当作专注练习，而不是治疗。如果担心自己的注意力或记忆，请咨询医生。
